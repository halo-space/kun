# Spec: 单元测试

## 目标

为 AI 选择器功能添加完整的单元测试覆盖。

## 测试范围

### 1. AiQuery 基础功能
- 创建查询
- 配置参数
- 默认值验证

### 2. 重试机制
- 成功场景
- 重试后成功
- 达到最大重试次数
- 不可重试错误

### 3. 超时处理
- 正常响应
- 超时场景

### 4. 错误处理
- API key 缺失
- 网络错误
- 无效响应

## Mock 策略

使用 mock OpenAI API 进行测试，避免实际 API 调用。

## 测试文件位置

`src/parser/ai.rs` 中的 `#[cfg(test)]` 模块
